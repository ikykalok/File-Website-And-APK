# Echo Music - Website Clone

Exact 1:1 replica of the official [Echo Music](https://echomusic.fun/) website.

## Features Included
- **Exact Visual Design & Typography**: Matches all layouts, colors, glassmorphism, responsive styles, gradients, and Google Fonts (`Inter`, `Unbounded`).
- **All High-Resolution Assets**:
  - Full screenshot showcase (`Home.png`, `search page.png`, `Material you music page.png`, `Apple inspired music page.png`, `lyrics.png`, `library.png`).
  - Animated logos (`Echo.gif`, `cat.gif`, developer avatar).
  - 63 frames for the dynamic animated favicon.
- **Interactive Functionality**:
  - **Live GitHub API Integration**: Dynamically fetches repository star count and total release download numbers with animated counting effects.
  - **Latest APK Download Link**: Dynamically binds release APK links to download buttons.
  - **Animated Favicon**: Automatically cycles through all 63 frames in the browser tab.
  - **Countdown Timer**: Wait timer with auto-unlocking direct download buttons.
  - **FAQ Accordion**: Expandable and collapsible interactive Q&A section.
  - **Interactive Support Bubble & Typewriter**: Typing animation with pet cat mascot and floating coffee support button.
  - **Easter Egg Celebrations**: Canvas confetti celebration on special dates (Echo Music's anniversary & developer's birthday).
  - **Material Ripple Effects**: Dynamic click and touch feedback on buttons.
  - **Scroll Reveal Animations**: Smooth entry animations for cards and sections via Intersection Observer.

## Quick Start (Completely Self-Contained)

Navigate to this folder and run:

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

To test or generate a production build:

```bash
npm run build
npm run start
```
